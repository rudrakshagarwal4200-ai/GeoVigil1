## 3. THE ENTERPRISE SECURITY & DATA GOVERNANCE SHIELD

Before a CFO allows 1,000 invoices to leave their office, they require answers to four mandatory security questions:

| Concern | Enterprise Security Response |
|:---|:---|
| **Data Training Policy** | **Contractually Binding Non-Training Guarantee**: Client financial records and rate cards are never used to train public or shared foundation models. All models run in isolated zero-retention tenant memory. |
| **Data Residency** | All data stored in AWS/Azure regional datacenters (UAE Central in Abu Dhabi/Dubai or US-East). |
| **Access Control** | Encrypted with AES-256 at rest and TLS 1.3 in transit. Dedicated isolated tenant database per client. |
| **System Access** | Read-only PDF/batch ingestion via secure SFTP or encrypted portal upload. **Zero write access to bank accounts or live general ledgers.** |
